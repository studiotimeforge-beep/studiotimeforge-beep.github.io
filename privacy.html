Privacy policy

This policy describes how Canali YouTube Claude ("the app") handles data. The app is a private tool used only by the owner of the YouTube channels it connects to. It has no other users.

YouTube API Services

The app uses YouTube API Services (YouTube Data API and YouTube Analytics API). By using the app you also agree to be bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

What data the app accesses

With the channel owner's consent, given on Google's consent screen, the app reads data about the owner's own YouTube channels: the list of videos, their public counts (views, likes, comments) and private analytics (views, engaged views, average view duration and percentage, subscribers gained, likes, comments, shares). It does not access data of other people's channels beyond what is publicly visible on YouTube.

How the data is used and stored

  • The data is used only to create private reports for the channel owner, saved as files on the owner's own computer.
  • The access token from Google is stored only on the owner's computer and is never published or shared.
  • The data is not sold, not used for advertising, and not shared with or transferred to third parties.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and tracking

The app and these web pages do not use cookies, analytics or tracking.

How to remove access and delete data

Access can be revoked at any time from the Google security settings page. Reports and stored access tokens can be deleted by deleting the files on the owner's computer; nothing is kept elsewhere.

Contact

Questions about this policy: use the user support email shown on Google's consent screen for this app.

In breve: lo strumento legge solo i numeri dei canali del proprietario, con il suo permesso; i dati restano sul suo computer e non vengono dati a nessuno. Il permesso si toglie da myaccount.google.com/permissions.
