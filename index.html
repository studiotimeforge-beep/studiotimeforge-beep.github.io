Canali YouTube Claude

Canali YouTube Claude is a private tool used only by the owner of a small group of YouTube channels. It runs on the owner's own computer and uses the YouTube Data API and the YouTube Analytics API, through YouTube API Services, to read the statistics of the owner's own channels (views, engaged views, watch time, subscribers, likes, comments, shares) and to help manage the owner's own videos.

It is not a public service: there is no sign-up and no other users. Access is granted only by the channel owner, through Google's own consent screen, and can be removed at any time.
